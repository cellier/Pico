# 更新记录

## 2026-10-19 · Pico 会议讲稿、语言与收尾

- 会前准备支持导入和编辑分段演示脚本，配对 Zoom Slides 文稿；根据实际共享状态、文稿身份和页码确认后开始讲解。
- 台词以声音实际播放完成为推进依据；支持等待听众回复、静默超时过渡、问答插话后续讲、明确暂停和本人接管，迟到或已取消的回调不能推进讲稿。
- 会议中可明确切换中英文；语言与当前发言关联，避免把引用、否定或其他人的文字误当切换指令。
- 明确收尾后进入自由交流；可在已准备的文稿内回看页面。明确道别及对应实时转写确认后，按设置播放告别并离开当前 Zoom 会议；本人接管、打断、重连或播放失败会取消离会。
- 本机主持人结束全场与 Pico 自己离开使用独立入口，不把参会者或模型的结束请求扩大为结束所有人的会议。
- 补充讲稿、语言、播放屏障、共享读回、退出驱动及取消恢复的离线回归；功能说明与实际验证边界见 [Pico 与 Zoom Slides](PICO-PRESENTATIONS.md)。
- Pico 识别中与语音失败不再弹出桌面悬浮提示，保留表情、任务状态和右键入口。

## 2026-10-15 · 划词翻译

- 在任意应用中用鼠标划选或双击选中文字后，选区正上方居中出现液态玻璃 **Translate** 按钮；点击别处、按键或滚动时消失。
- 优先通过辅助功能读取选中文字和位置；Chromium / Electron 等读不到时，仅在指针为文本光标时用 ⌘C 读取并立即恢复剪贴板。密码框不处理。
- 点击后打开深色玻璃对话框：顶部为原文（点按展开），下方流式显示译文；中文译为英文，其他语言译为简体中文，要求自然地道。悬停译文可一键复制。
- 底部 **Ask Telos** 可继续追问或交代其他事情：首次发送会带上原文和译文创建 Telos 任务，对话直接显示在对话框内，也可在 Telos 中打开。Esc 或关闭按钮关闭。
- 翻译使用 Settings 中已配置的模型；`TELOS_PREVIEW=translation` 可在隔离预览中查看按钮和对话框。

## 2026-10-16 · Hermes 与 iPhone 镜像

- Hermes Agent 升至用户指定的 v0.22.0，固定提交 `e06df9c2eae6901f4c88f464e0ae6e753c0428b8`；主运行环境迁移 Python 3.14，本地语音环境保持 Python 3.12。
- 安装官方目录固定提交的 phone-harness 插件 v0.1.0（Python 包 0.3.2），通过本机 iPhone Mirroring 控制已连接的手机。
- 普通任务加载手机工具，Feed 保持隔离；执行接入 Telos 原有确认设置，加入跨任务互斥和取消处理。
- 修复手机工具将 iPhone 镜像的主屏幕、应用切换器按钮误判为连接阻塞的问题，连接及认证提示仍会停止执行。
- 手机截图可直接在当前任务中查看，并提供原图尺寸和坐标提示，避免临时文件路径与缩放裁图影响操作。
- 修复手机文字识别默认只识别英文、漏掉中文联系人，以及中文应用名称无法输入的问题；优先按精确文字位置导航。微信启动按精确应用名称定位，避免搜索回车误选其他相似应用。
- 补齐官方安装包缺失的手机操作说明，使执行引擎能读取对应平台的能力与用法。
- 修复详情长消息和连续操作确认触发的布局卡死，合并流式刷新及常规保存，减少主线程负担。
- 每轮结果先保存准确终态；应用重启只恢复匹配该轮的结果，拒绝旧记录并避免重复执行手机操作。
- 执行达到上限或中断时保留完整历史并显示具体原因；手机任务继续前先核对实际发送状态，避免重复发送。
- 构建、依赖固定与发行打包支持新版运行环境，插件文件保留上游版本和完整性校验。

## 2026-10-14 · 近期开发版同步

本次把 10 月 12—14 日的本地开发更新整理进同一仓库。现有介绍视频继续保留；本次提交不创建新发行标签或 DMG。

### Pico 桌面伙伴

- 新增 `Pico/` 源码、离线 Three.js 依赖及许可证、构建入口和可复用测试。
- 保留经典 Pico，增加粉色花朵与默认白气球皮肤，右键可切换并记住选择。
- 改善按住、点击、等待和工作状态的表情；白气球默认双眼对称、嘴型使用基础规则形状，开心爱心保持比例并改善边缘。
- 根据所在屏幕和摆放位置轻轻望向屏幕中心，横向最多约 9.2°、纵向位置影响最多约 4.6°；拖动后平滑调整。
- 百炼账户优先复用 Telos Settings 中的配置，重启后继续使用；保留旧账户兼容读取。
- 仓库构建去除个人绝对应用路径，保留按住说话、拖动、点击穿透及任务/会议入口。

### Telos 语音与响应

- 百炼 API Key、地域和业务空间在 Settings 中持久保存，Telos 与 Pico 可共用。
- 混合中英文语音输入增加语言和产品名提示；Telos 云端识别失败时明确提示并恢复本地识别。
- 自动插入文字产生的粘贴事件不再显示为演示用的 ⌘V；手动按键与按住显示保留。
- 长消息输入、对话显示与持久化路径增加有界处理，改善长文下的界面响应。
- 菜单栏日程两行排列，区域最多 320 点并按可用空间收窄。

### 录屏、执行与会议

- 增加整屏、窗口和区域录屏，可选麦克风、摄像头及系统声音。
- 文字/语音任务默认自动执行，可在 Settings 切回手动确认；系统权限与身份验证仍由系统处理。
- 加入百炼双通道实时会议转写、会前材料、长期记忆工具和试用中的 Pico 会议代理。
- 会议检测、音频捕获、转写及代理会话各自管理生命周期；音频错误会标记或停止，不把模型回复当成用户承诺。

### 构建与维护

- 更新不再主动重置系统权限。构建拒绝覆盖运行中的目标，并只使用明确指定或既有的签名身份。
- 不自动创建钥匙串、导入证书或修改系统信任；新 checkout 的签名选项见主 README。
- 两个语音设置测试使用同一段可在本机重新生成的合成语音，生成脚本见 `Pico/scripts/generate-voice-fixture.sh`，没有使用个人录音。
- 本机任务、密钥、会议准备讲稿、运行日志、模型及应用构建不纳入提交。

开发与测试通过不等于所有云端模型、Zoom 版本、音频设备和真实会议场景都已经端到端验收。会议试用范围、数据流向和安装限制以主 README 为准。
