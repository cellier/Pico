# 更新记录

## 2026-10-14 · 近期开发版同步

本次把 10 月 12—14 日的本地开发更新整理进同一仓库。现有介绍视频继续保留；本次提交不创建新发行标签或 DMG。

### Pico 桌面伙伴

- 新增 `Pico/` 源码、离线 Three.js 依赖及许可证、构建入口和可复用测试。
- 保留经典 Pico，增加粉色花朵与默认白气球皮肤，右键可切换并记住选择。
- 改善按住、点击、等待和工作状态的表情；白气球默认双眼对称、嘴型使用基础规则形状，开心爱心保持比例并改善边缘。
- 根据所在屏幕和摆放位置轻轻望向屏幕中心，横向最多约 9.2°、纵向位置影响最多约 4.6°；拖动后平滑调整。
- 百炼账户优先复用 Telos Settings 中的配置，重启后继续使用；保留旧账户兼容读取。
- 仓库构建去除个人绝对应用路径，保留按住说话、拖动、点击穿透及任务/会议入口。

### Telos 语音与响应

- 百炼 API Key、地域和业务空间在 Settings 中持久保存，Telos 与 Pico 可共用。
- 混合中英文语音输入增加语言和产品名提示；Telos 云端识别失败时明确提示并恢复本地识别。
- 自动插入文字产生的粘贴事件不再显示为演示用的 ⌘V；手动按键与按住显示保留。
- 长消息输入、对话显示与持久化路径增加有界处理，改善长文下的界面响应。
- 菜单栏日程两行排列，区域最多 320 点并按可用空间收窄。

### 录屏、执行与会议

- 增加整屏、窗口和区域录屏，可选麦克风、摄像头及系统声音。
- 文字/语音任务默认自动执行，可在 Settings 切回手动确认；系统权限与身份验证仍由系统处理。
- 加入百炼双通道实时会议转写、会前材料、长期记忆工具和试用中的 Pico 会议代理。
- 会议检测、音频捕获、转写及代理会话各自管理生命周期；音频错误会标记或停止，不把模型回复当成用户承诺。

### 构建与维护

- 更新不再主动重置系统权限。构建拒绝覆盖运行中的目标，并只使用明确指定或既有的签名身份。
- 不自动创建钥匙串、导入证书或修改系统信任；新 checkout 的签名选项见主 README。
- 两个语音设置测试使用同一段可在本机重新生成的合成语音，生成脚本见 `Pico/scripts/generate-voice-fixture.sh`，没有使用个人录音。
- 本机任务、密钥、会议准备讲稿、运行日志、模型及应用构建不纳入提交。

开发与测试通过不等于所有云端模型、Zoom 版本、音频设备和真实会议场景都已经端到端验收。会议试用范围、数据流向和安装限制以主 README 为准。
